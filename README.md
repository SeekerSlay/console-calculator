\# ConsoleCalculator

Консольный калькулятор на Qt (сигналыслоты, QObject, MOC) с юнит-тестами (QTest, QSignalSpy). Вариант #4.



\## Сборка и запуск

qmake ConsoleCalculator.pro \&\& make \&\& .ConsoleCalculator



\## Тесты

cd tests \&\& qmake CalculatorTests.pro \&\& make \&\& .CalculatorTests



\## Команды

addsubmuldiv a b, reset, help, quit
